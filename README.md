## Featured Projects

### 🛰️ [Intelligent Orbital Debris Removal Planner](https://github.com/KaramQ6/debris-removal-planner)
Dual-layer AI system for propellant-constrained orbital debris collection. A **MaskablePPO** agent trained in a custom 3D Keplerian physics environment learns multi-target collection sequences that minimize total Delta-V — paired with a **RAG advisory layer** (BM25 over NASA/ESA debris-mitigation guidelines) that gives mission teams grounded, real-time recommendations. Deterministic seeded runs for reproducible evaluation.

`Python` `Stable-Baselines3` `Gymnasium` `PyTorch` `RAG / BM25` `Pytest`

### 🐍 [agentflow](https://github.com/KaramQ6/agentflow) — `pip install agentflowkit`
Async-first multi-agent pipeline framework, **published to [PyPI](https://pypi.org/project/agentflowkit/)**. Decorator-based API, composable pipelines, and Pydantic-validated structured outputs at every boundary — built for ergonomics and concurrent agent throughput.

`Python` `AsyncIO` `Pydantic` `PyPI`

### 🤖 [AI Crew Studio](https://github.com/KaramQ6/ai-crew-studio)
Full-stack orchestration platform where autonomous agent crews collaborate in real time — server-side orchestration, low-latency token streaming over WebSockets, and a React mission-control dashboard.

`Python` `React` `WebSockets`

### 💼 [karamdev.com](https://www.karamdev.com)
Personal portfolio: glassmorphic bento-grid design, GSAP scroll-driven animation, integrated scheduling engine. Vite-optimized, edge-delivered on Vercel.

`React` `GSAP` `Tailwind` `Vite` `Vercel`
