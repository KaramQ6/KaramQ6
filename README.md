## Featured Projects

### 🐍 [agentflow](https://github.com/KaramQ6/agentflow) — `pip install agentflowkit`
Async-first multi-agent pipeline framework, **published on [PyPI](https://pypi.org/project/agentflowkit/)**.
- Features asynchronous execution loops with dynamic tool dispatching and fallback heuristics that decreased infinite agent loops by **40%**.
- Implemented strict Pydantic data boundary validation and automated CI/CD evaluation suites with **95%+ test coverage** (`mypy --strict`, `pytest`).

`Python` `AsyncIO` `Pydantic` `PyPI` `mypy` `pytest`

### 🤖 [AI Crew Studio](https://github.com/KaramQ6/ai-crew-studio)
Full-stack orchestration platform where autonomous agent crews collaborate in real time.
- Prototyped lightweight FastAPI and WebSocket backends to execute agent DAGs, stream tokens, and monitor inference latency across model endpoints.
- Integrated **Model Context Protocol (MCP)** connectors, enabling secure agentic tool access to external SQL databases and file systems.

`FastAPI` `React` `WebSockets` `MCP` `SQL`
